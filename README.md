# Ahmed Talaat Ahmed Portfolio

## Run
1. Open this folder in VS Code.
2. Run:
   npm install
3. Then:
   npm run dev
4. Open the localhost URL shown by Vite.

## CV
The original uploaded CV is included as:
`public/Ahmed-Talaat-Ahmed-CV.docx`

If you want the navbar "Download CV" button to download a PDF instead, export the CV to PDF and rename it:
`public/Ahmed-Talaat-Ahmed-CV.pdf`
Then change the href in `src/components/Navbar.jsx` from `.pdf` as already written.

## Technologies
React, Bootstrap 5, JavaScript, CSS, Bootstrap Icons.
